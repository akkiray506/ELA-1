DEEP LEARNING PHISHING EMAIL CLASSIFIER
========================================

Files:
1. Phishing_Email_BiLSTM_Colab.ipynb
   Complete Google Colab notebook. Upload this notebook and the CSV to Google Colab.
   Set Runtime -> Change runtime type -> T4 GPU (if available), then Run all.

2. synthetic_email_dataset.csv
   2,400 synthetic email messages:
   - 1,200 phishing
   - 1,200 legitimate

3. Phishing_Email_Classifier_Report.pdf
   Three-page project report. The numerical result fields are intentionally marked
   as "GENERATED BY NOTEBOOK" because exact metrics must come from the actual training run.
   After running the notebook, replace those fields and paste the generated plots/confusion matrix
   if your evaluator requires the report to contain the actual run outputs.

IMPORTANT:
The notebook is designed for TensorFlow/Keras and Google Colab. It accepts raw email strings
at inference time and returns a phishing probability.

Suggested Colab steps:
1. Open Google Colab.
2. Upload the .ipynb and synthetic_email_dataset.csv.
3. Select T4 GPU if available.
4. Run all cells.
5. Download phishing_email_bilstm.keras and model_metrics.csv.
6. Make the final report visually complete by inserting the generated plots and actual metrics.

Dataset note:
The dataset is synthetic and was created specifically for this academic project. It does not
contain real people's emails or credentials.
